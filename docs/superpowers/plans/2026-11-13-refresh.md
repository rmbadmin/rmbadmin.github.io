# Blog refresh Implementation Plan

**Goal:** Refresh the existing static blog without breaking its content or URLs.
**Architecture:** One-time extract legacy bodies and route metadata into JSON; standard-library Python renders HTML. CSS/JS are progressive enhancements. No JavaScript framework or production dependencies.
**Tech Stack:** HTML, CSS, vanilla JavaScript, Python 3.
**Spec:** ../specs/2026-11-13-refresh-design.md

## Global constraints
- Preserve CNAME, all old URLs, article bodies and heading IDs.
- Keep comments disabled until explicit owner configuration.
- Changes go to a separate review branch and draft PR only; no merge or publication.

## Review focus
- Chinese routes and index.html variants stay valid.
- Long code, tables and mobile navigation never overflow viewport.
- Search is keyboard accessible, empty and no-match states work.
- Theme respects system and persisted choice without blocking content.
- Missing comments setup shows truthful explanation, no fake live form.
